# Showcase app: Reel Tracker

Reel Tracker is a small Compose Multiplatform movie tracker for Android and iOS, built on live data from [TMDB](https://www.themoviedb.org). It lives in `showcase-app/` in the repository. It has no UI test code: every on-device check is a platform-agnostic JSON scenario, and one file runs on both platforms.

Its walkthrough takes you from a fresh clone to replaying a shipped scenario on an Android emulator, replaying the same file on an iOS simulator, then recording a flow of your own with your AI agent and replaying it on the other platform.

Follow the [full walkthrough](https://github.com/sh3lan93/mobile-automator/blob/main/showcase-app/README.md#walkthrough) in the app's README.
